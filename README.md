## 🌟 Features

- **⚡ Dual NLP Engines**:
  - `⚡ HumanizeAI Pro`: Multi-pass contextual humanizer with synonym diversity and academic cadence.
  - `🧠 GhostWriter Ultra`: Organic human voice with relaxed syntax and sentence length variance.
  - `🎓 Academic Master`: Scholarly tone tailored for university essays and research papers.
  - `🌊 Natural Flow`: Conversational, fluid writing style with natural connective tissue.
- **🛡️ Smart Markdown Sanitizer**:
  - Automatically cleans AI asterisks (`*`, `**`), headers (`#`), backticks (```), and broken punctuation before typing to ensure 0 markdown prompts in Google Docs.
- **⌨️ Real OS Keystroke Synthesis**:
  - Rootless keyboard typing via `pynput` and `xdotool` fallback.
  - Cognitive punctuation pauses, false-start fragments, and real-time EMA WPM speedometer.
- **🧪 Real-time Playground**:
  - 50/50 dual dark theme editor with live perplexity, burstiness, and AI score analysis.
- **🌐 Universal Bookmarklet**:
  - Injects native browser typing directly into Google Docs, Word Online, or GPTZero from any browser.

## 🚀 Quick Start (Local)

```bash
git clone https://github.com/drylexx3/HumanNatureWeb.git
cd HumanNatureWeb
pip install -r requirements.txt
./run_web.sh
```
Open [http://localhost:5050](http://localhost:5050) in your browser.
